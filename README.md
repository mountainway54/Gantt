# 專案甘特圖使用說明

開啟 [專案甘特圖](https://mountainway54.github.io/Gantt/)，使用團隊提供的共用電子郵件和密碼登入。團隊成員可以透過同一個雲端專案庫查看和編輯排程。

## 建立或開啟專案

1. 在左側面板最上方的 **專案檔案**，按 **＋ 新專案**，或按 **開啟專案** 從清單選擇已有的專案。
2. 在 **專案資訊** 填寫專案名稱和開始日期。
3. 按 **＋ 新增任務**，再點任務列展開，填寫任務名稱、負責人、開始與結束日期。也可以加入備註或設定前置任務。

可拖曳甘特圖上的長條調整排程。設定前置任務後，後續任務會排在前置任務結束之後，前置任務改期也可能帶動後續任務。

## 儲存到雲端

每次完成編輯後，到 **專案檔案** 按 **💾 儲存**，等畫面顯示 **已儲存**。如果看不到按鈕，把滑鼠移到左側面板並往上捲到最頂端。儲存會提交整份專案及其任務。

- **重新整理後看到空白專案**時，按 **開啟專案**，從清單找回已儲存的排程。
- **遇到版本衝突**時，表示雲端版本已有變動。可先按 **另存新檔** 保留自己的修改，再用 **開啟專案** 查看雲端版本。
- **刪除專案**會從共用專案庫移除該專案，影響所有團隊成員。

## 匯出與匯入

- **PDF、JPG、Excel**｜從右上方工具列匯出目前的甘特圖。PDF 和 JPG 可選 A4 直式或橫式。
- **匯出專案檔**｜在左側 **專案檔案** 下載 JSON，供備份或搬移。
- **匯入專案檔**｜選擇先前匯出的 JSON，系統會建立一份新的雲端專案。
